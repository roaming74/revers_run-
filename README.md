# ⚡ ReversRun

**ReversRun** — удобная панель управления ПК с таймером.  
Выключение, перезагрузка, WinRE и спящий режим — через заданное время.

**Автор:** VladGames  
**Версия:** 1.0.0  
**Год:** 2026

---

## 🎯 Что умеет

| Кнопка | Действие |
|--------|----------|
| 🔴 **Выключить** | Выключение ПК через заданное время |
| 🔄 **Перезагрузить** | Перезагрузка через заданное время |
| 🛠 **WinRE** | Загрузка в среду восстановления Windows |
| 💤 **Спящий режим** | Уход в сон через заданное время |
| ❌ **ОТМЕНИТЬ** | Отмена запланированного действия |

---

## 🚀 Как пользоваться

1. **Запусти** `Revers_run.exe` (от имени администратора)
2. **Введи** время в поля: **часы**, **минуты**, **секунды**
   - Например: `0` ч `5` м `0` с = через 5 минут
   - Например: `1` ч `30` м `0` с = через 1 час 30 минут
3. **Нажми** нужную кнопку
4. **Подтверди** действие в окне
5. **Смотри** на таймер (`00:00:00`) и прогресс-бар
6. Если **передумал** — нажми **❌ ОТМЕНИТЬ**

## ⚙️ Требования

- **Windows 10 / 11**

- **Спящий режим** работает только на **реальном ПК** (не в виртуалке)
